# What is Ascend

Ascend is a free-for-all evolution-style minigame built on [Tea](../tea/intro.md). You start as a basic morph. Each kill unlocks an evolve, and you sneak on solid ground for three seconds to advance a stage. The first player to reach the apex form wins.

It ships as a single plugin that depends on TeaCore and LibsDisguises. Install it on each server that should host Ascend matches. Tea provides the lobby, matchmaking and cross-server routing.
